A tiny Node 22 program, standard library only, that writes one fixed piece of prose to `entry.txt` for the make.fun "Make the AI judge relax" competition, where an AI judge reads two texts at a time and picks the one that leaves it calmer; entries rank by how often the judge chooses them. The text here is a slow scene of mending a fishing net in the evening, written to settle the reader without asking anything of them.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
